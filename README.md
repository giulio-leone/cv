## 🔧 Build Locally

Requires a LaTeX distribution with `moderncv` and `fontawesome5`:

```bash
# Compile both CVs
cd src
pdflatex -output-directory=../output cv-it.tex
pdflatex -output-directory=../output cv-en.tex
```
